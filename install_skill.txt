INSTALL THE SIMULATION-BUILDER SKILL (claude.ai, free account)

What it does: Claude asks you the questions from today's seven tasks,
writes one HTML simulation, and checks it with the check list.
You do not need to paste the prompts any more.

This is optional. Today's prompts work in any chatbot without it.


ONCE: TURN ON CODE EXECUTION
1. Open claude.ai and sign in.
2. Go to Settings > Capabilities.
3. Turn on "Code execution and file creation"
   (in the newer menu it is called "Create and edit files").


ONCE: UPLOAD THE SKILL
1. Download simulation-builder.zip from this kit. Do NOT unzip it.
2. Go to Customize > Skills.
3. Click "+ Add", then "Upload skill".
4. Choose simulation-builder.zip and click "Upload".
5. The skill appears in your list. Check that it is turned on.


EVERY TIME
Start a new chat. Type / and choose simulation-builder, or write:
   Help me build a simulation for my class.
Claude uses the skill and asks you one question at a time.


IF IT DOES NOT WORK
- Check that code execution is still on (Settings > Capabilities).
- Check that the skill is turned on (Customize > Skills).
- Write "Use the simulation-builder skill." in the chat.
- Still nothing? Use the prompts in prompts.txt. They do the same job.


Source: Claude Help Center, "Use Skills in Claude"
https://support.claude.com/en/articles/12512180-use-skills-in-claude
Checked 3 November 2026: skills are listed for Free, Pro, Max, Ultra, Team
and Enterprise plans, and they need code execution turned on.
Menus may change. If a name differs, look for "Skills" or "Capabilities".
